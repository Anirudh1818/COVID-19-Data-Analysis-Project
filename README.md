# COVID-19 Data Analysis

## About the Project

This project focuses on analysing COVID-19 data from different countries using Python.

The main objective is to explore COVID-19 cases, deaths, death percentages and continent-wise statistics through Exploratory Data Analysis (EDA).

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Objectives

- Perform basic Exploratory Data Analysis.
- Explore and understand the COVID-19 dataset.
- Identify and handle missing values.
- Compare countries based on total COVID-19 cases and deaths.
- Analyse COVID-19 death percentages across countries.
- Compare total cases across different continents.
- Study relationships between population, total cases and total deaths.
- Calculate Spearman rank correlation.

## Dataset

The project uses the COVID-19 Coronavirus dataset containing country-wise information, including population, continent, total cases, total deaths and death percentage.

## Analysis Covered

- Data loading and inspection
- Dataset shape and structure
- Missing value analysis and handling
- Descriptive statistical analysis
- Column renaming
- Top five countries with the highest COVID-19 cases
- Five countries with the lowest COVID-19 cases
- Country-wise COVID-19 death analysis
- Death percentage comparison
- Continent-wise total case analysis using groupby()
- Population vs Total Cases scatter plot
- Total Cases vs Total Deaths scatter plot
- Spearman rank correlation
- Correlation heatmap

## Project Files

- `COVID_19_Data_Analysis_Project_2.ipynb` – Python analysis notebook.
- `COVID-19 Coronavirus.csv` – Dataset used for analysis.

## Key Learning Outcomes

Through this project, I practised working with Pandas, analysing real-world data, handling missing values, creating visualisations and interpreting statistical relationships between different numerical variables.
